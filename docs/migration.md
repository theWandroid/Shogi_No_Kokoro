# Migració

Les antigues pàgines ca/*.html i es/*.html passen a *.html?lang=ca i *.html?lang=es. Configura redireccions al servidor si aquestes URL s’han publicat abans. En aquesta entrega no s’ha desplegat res.

La versió actual substitueix les carpetes duplicades per un HTML per pàgina. i18n.js controla idioma, metadades, atributs accessibles i preferència local. Traduccions carregades per HTTP; el català queda a l’HTML de reserva.

Abans de publicar: revisar dades de contacte, sessions, localització i permisos del logotip. El segell tipogràfic és provisional. Les imatges són decoratives generades amb IA. No hi ha panell d’edició WordPress ni enviament de formularis. Els recursos històrics de WordPress continuen sent externs.
